# To-Do List App

A responsive task management application built with HTML, CSS, and JavaScript.

This project was created to strengthen my front-end development skills and give me hands-on practice working with DOM manipulation, event handling, form validation, localStorage, responsive design, and accessibility.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete
- Add optional due dates
- Add optional task descriptions
- Save tasks using localStorage
- Add tasks using the Enter key
- Keyboard-accessible Edit and Delete controls
- Responsive layout for desktop and mobile
- Form validation to prevent blank tasks

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Accessibility Improvements

The original version of the project used non-semantic elements for the Edit and Delete controls.

I later improved the application by:

- Converting Edit and Delete controls into real buttons
- Adding `aria-label` attributes
- Adding visible keyboard focus states
- Adding proper labels to form inputs
- Making the controls accessible through keyboard navigation
